## GIS Glossary   

 
| Term                 | Description                                                                                     |
|----------------------|------------------------------------------------------------------------------------------------|
| Attribute table      | A table storing descriptive information about spatial features for analysis and queries       |
| Buffer               | An area around a feature showing distance or closeness                                        |
| CRS (Coordinate Reference System)  | A system that includes coordinate system, datum and projection details for accurate location referencing |
| Digitization         | The process of converting the geographic features on an analog map into digital x,y coordinates or spatial data |
| EPSG  (European Petroleum Survey Group)               | A standardized coding system for coordinate reference systems and map projections used worldwide in GIS software |
| GCP (Ground Control Points) | A coordinate system defining locations on Earth's curved surface using latitude and longitude in angular units |
| GCS (Geographic Coordinate System) | Identifies locations on the curved surface of the Earth. Locations are defined by latitude and longitude values |
| Geocoding | Matching addresses to geographical coordinates (latitude & longitude)                                   |
| Georeferencing       | Aligning map data to real-world locations                                                     |
| GIS (Geographic Information Systems)                 | A system to capture, analyze and map geographic information   |
| GIS software         | Applications like QGIS used to create, view and analyze GIS data                   |
| Metadata             | Information about the origin and details of data                                             |
| PCS (Projected Coordinate System) | Identifies locations & measuring features on a flat surface. Examples are conical, cylindrical and azimuthal projections |
| Projection           | A technique for flattening the Earth’s surface onto a 2D map                                 |
| UTM (Universal Transverse Mercator) |A coordinate system that divides the Earth into zones for accurate, local-scale mapping | 
| Radiometric resolution | The sensor's ability to distinguish brightness levels, often measured in bits per pixel |
| Raster data          | A grid of cells representing data like images or measurements                                |
| Remote Sensing       | Collecting data about the Earth from satellites or planes                                   |
| RMSE (Root Mean Square Error)| A statistical measure of accuracy, calculating the average difference between measured coordinates and known GCP locations|
| Scale                | Shows how much detail or area is on a map                                                    |
| Spatial analysis     | Techniques for finding patterns or relationships in spatial data                            |
| Spatial data         | Data showing where features are located on Earth                                             |
| Spatial extent       | The geographical area or physical boundary over which something exists, is measured or has an effect|
| Spatial query        | A statement or logical expression that selects geographic features based on location or spatial relationship|
| Spatial resolution   | The dimensions of the area on the ground represented by a single cell in a raster or pixel in an image |
| Spectral resolution  | The range of wavelenghts that a single band in an imaging system can detect |
| Temporal resolution  | The ability of a system to accurately represent changes over time |
| Vector data          | Geographic data represented by points, lines and polygons for detailed feature mapping      |
